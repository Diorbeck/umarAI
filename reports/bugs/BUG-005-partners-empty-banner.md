# BUG-005 — Пустой белый баннер на страницах «Партнёры» и «Строительные компании»

- **Статус подтверждения:** Подтверждён (2 визита с интервалом ~7 минут + вторая страница)
- **Severity:** MINOR
- **Priority:** P2
- **Среда:** Chrome (macOS), десктоп, 27.07.2026
- **Предусловия:** нет

**Шаги воспроизведения:**
1. Открыть /ru/partners (или /ru/partners/construction-companies).
2. Осмотреть верхний блок страницы (высота ~1050 px по DOM, в кадре ~370 px).

**Ожидаемый результат:** баннер с изображением и заголовком («С хорошим агентом результат лучше»).
**Фактический результат:** большой пустой белый скруглённый блок; текст и изображение не отображаются (по DOM в блоке есть текст и 1 img, но визуально блок пуст).

- **Частота:** 3/3 (partners — дважды, construction-companies — один раз; на обеих страницах одинаково).
- **Доказательства:** скриншоты `13-partners-empty-hero-repro1.jpg`, `23-partners-empty-hero-repro2.jpg`, `14-construction-companies-empty-hero.jpg`; DOM-замер: `{firstBlockH:1050, firstBlockText:"С хорошим агентом результат лучше…", firstBlockImgs:1}`.
- **Влияние на бизнес:** партнёрский раздел выглядит сломанным для агентов и застройщиков — имиджевая потеря.
- **Предполагаемая причина:** изображение баннера не загружается/белый текст на белом фоне (стиль или отсутствующий asset).
- **Рекомендация:** проверить URL изображения баннера и цвет текста; добавить fallback-фон.
- **Что проверить после исправления:** баннер на обеих страницах и 3 локалях, desktop + mobile.
