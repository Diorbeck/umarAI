# BUG-003 — SEO: пустой title, отсутствуют description/OG/canonical, неверный lang

- **Статус подтверждения:** Подтверждён (5+ страниц, повторные замеры)
- **Severity:** MAJOR
- **Priority:** P1
- **Среда:** Chrome (macOS), 27.07.2026
- **Предусловия:** нет

**Шаги воспроизведения:**
1. Открыть /ru (а также /ru/search, /ru/login, /ru/announcements/{uuid}).
2. Проверить `document.title`, `meta[name=description]`, OG-теги, `link[rel=canonical]`, `html lang`.

**Ожидаемый результат:** уникальные title/description на каждой странице, OG-теги для шаринга, canonical, `lang="ru"`/`"uz"`/`"en"` по локали.
**Фактический результат:**
- `document.title` = "" (пустой) на главной, поиске, объявлении, входе (вкладка показывает голый URL).
- `meta description` — нет; OG-тегов — 0; canonical — нет.
- `html lang="en"` на русской и узбекской версиях.

- **Частота:** 100% (все проверенные страницы, замеры повторены на повторных загрузках).
- **Доказательства:** JS-замеры в сессии: `{title:"", desc:null, og:[], canonical:null, lang:"en"}` (главная /ru); аналогично /ru/search, /ru/login, объявление; /uz — `lang:"en"`.
- **Влияние на бизнес:** сайт практически невидим для Google/Yandex → потеря бесплатного трафика; при шаринге в Telegram/соцсети нет превью; вкладки браузера без названия. Вместе с BUG-007 (карточки не «ссылки») объявления не индексируются.
- **Предполагаемая причина:** в Next.js не заполнен Metadata API (generateMetadata) для страниц.
- **Рекомендация:** задать title/description/OG/canonical для всех публичных страниц; для объявлений — генерировать из данных (заголовок, цена, район); выставлять lang по локали; добавить sitemap.xml и robots.txt (не проверялись — проверить).
- **Что проверить после исправления:** title/description на каждой странице и локали, превью ссылки в Telegram, валидность OG (opengraph.xyz), lang, наличие sitemap.
