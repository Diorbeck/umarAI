# BUG-001 — Карта не отрисовывается на странице /ru/search/map

- **Статус подтверждения:** Подтверждён (3/3 воспроизведения)
- **Severity:** MAJOR
- **Priority:** P1
- **Среда:** Chrome (macOS), десктоп ~1512×791, 27.07.2026, HTTPS, Cloudflare
- **Предусловия:** нет (гость, без входа)

**Шаги воспроизведения:**
1. Открыть объявление, напр. `/ru/announcements/7cd1c670-5817-44a5-87c8-9353f8e8fc72` (ID: RA17).
2. Нажать «Посмотреть на карте» (ссылка `/ru/search/map?id=RA17&ll=69.2946346903422,41.28013156701279`).
3. Ждать 10–15 секунд.

**Ожидаемый результат:** карта Google с маркером объекта.
**Фактический результат:** сначала «Loading map…», затем сплошной бежевый фон без тайлов, маркеров и элементов управления. Через 15+ секунд ничего не меняется.

- **Частота:** 3/3 на /ru/search/map (две загрузки + повтор с ожиданием). Встроенная карта на /ru/search: 1-я загрузка — пустая, 2-я — карта отрисовалась (маркеры видны), т.е. проблема нестабильная, но на выделенной странице — стабильная.
- **Доказательства:** скриншоты `11-map-page-empty-repro2.jpg`, `12-map-page-empty-repro3.jpg`, `06-search-map-empty-repro1.jpg`, `21-search-map-rendered.jpg` (успешный случай для сравнения). Сеть: maps.googleapis.com JS загружается (200), DOM содержит `.gm-style` и canvas, но тайлы не запрашиваются. Ошибок в консоли нет. Один раз зафиксирован 503 на `…/ru/search/map…&_rsc=…`.
- **Влияние на бизнес:** ключевой сценарий «посмотреть, где находится объект» не работает — потеря доверия и конверсии.
- **Предполагаемая причина:** ошибка инициализации Google Maps (не вызывается setCenter/зум до готовности контейнера, либо проблемы ключа/биллинга без вывода ошибки в консоль).
- **Рекомендация:** проверить инициализацию карты (размер контейнера в момент `new google.maps.Map`), консоль Google Cloud (квоты/биллинг/ограничения ключа), добавить обработку ошибок и fallback.
- **Что проверить после исправления:** карта с маркером на /ru/search/map (10 загрузок подряд), встроенная карта /ru/search, снятие надписи «Loading map…» после рендера.
