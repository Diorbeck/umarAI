# BUG-002 — Отсутствует мобильная вёрстка (≤390 px): горизонтальный скролл, нет мобильного меню

- **Статус подтверждения:** Подтверждён на уровне CSS-брейкпоинтов (3 страницы × воспроизведение); требуется контрольная проверка на реальном устройстве (методика — эмуляция ширины viewport через iframe 390×700, media queries применяются)
- **Severity:** CRITICAL (мобильный трафик — основной канал в Узбекистане)
- **Priority:** P0 (после подтверждения на устройстве; иначе P1)
- **Среда:** Chrome (macOS), эмуляция viewport 390×844 (iframe same-origin), 27.07.2026
- **Предусловия:** нет

**Шаги воспроизведения:**
1. Открыть /ru (или /ru/search, или страницу объявления) при ширине окна/viewport 390 px.
2. Осмотреть шапку и контент, измерить `document.documentElement.scrollWidth`.

**Ожидаемый результат:** адаптивная вёрстка: бургер-меню, контент в одну колонку, без горизонтальной прокрутки.
**Фактический результат:**
- Главная: scrollWidth 1130 px при viewport 384 px; десктопная шапка («Покупка Аренда Партнеры…») уходит за экран; hero-текст обрезан; бургер-меню отсутствует (проверено по DOM: кнопки-гамбургера нет).
- Поиск: заголовок «Объекты недвижимость для р…» обрезан, шапка обрезана.
- Объявление: scrollWidth 1120 px при 384 px.

- **Частота:** 3/3 страницы, стабильно.
- **Доказательства:** зум-скриншоты в сессии (главная 390px, поиск 390px, объявление 390px); DOM-замеры: `{scrollW:1130, vw:384, burger:false}`, `{scrollW:1120, vw:384}`.
- **Влияние на бизнес:** большинство посетителей с телефонов не смогут нормально пользоваться сайтом → прямая потеря лидов и высокий показатель отказов; реклама в Instagram/Telegram будет вести на неюзабельный сайт.
- **Предполагаемая причина:** не реализованы мобильные брейкпоинты (Tailwind-классы только для десктопа), нет мобильного компонента шапки.
- **Рекомендация:** реализовать адаптив ≤768px (шапка-бургер, стек колонок, ограничение ширины карточек), затем проверить на реальных iPhone/Android (DevTools device mode + устройства).
- **Что проверить после исправления:** отсутствие горизонтального скролла на 320/390/768 px для главной, поиска, объявления, входа; работоспособность бургер-меню; кликабельность карточек пальцем.
