# BUG-007 — Карточки объявлений не являются ссылками (div + onclick)

- **Статус подтверждения:** Подтверждён (DOM-анализ /ru/search, 96 карточек; повторно на главной — карусель)
- **Severity:** MAJOR (SEO + доступность + UX)
- **Priority:** P2
- **Среда:** Chrome (macOS), 27.07.2026
- **Предусловия:** нет

**Шаги воспроизведения:**
1. Открыть /ru/search.
2. Выполнить в консоли поиск ссылок на объявления: `document.querySelectorAll('a[href*="/announcements"]').length` → 0; при этом карточек с классом card — 96, у карточки `cursor-pointer` и клик-обработчик.
3. Попробовать открыть карточку в новой вкладке (Cmd+клик / средняя кнопка) — открытия не происходит.

**Ожидаемый результат:** каждая карточка — `<a href="/ru/announcements/…">`: открывается в новой вкладке, доступна с клавиатуры (Tab/Enter), индексируется поисковиками.
**Фактический результат:** карточка — `<div data-slot="card" class="… cursor-pointer">` без href; переход только JS-кликом.

- **Частота:** 100% (все карточки на /ru/search и на главной).
- **Доказательства:** DOM-выгрузка списка всех `a[href]` страницы поиска — ссылок на объявления нет (только /ru, /ru/login, search?…); outerHTML карточки в сессии.
- **Влияние на бизнес:** (1) Google не видит страницы объявлений → нет поискового трафика на карточки; (2) пользователи не могут открыть несколько квартир в вкладках для сравнения — базовый сценарий на классифайдах; (3) недоступно с клавиатуры и для скринридеров.
- **Предполагаемая причина:** навигация реализована через router.push в onClick вместо `<Link>`.
- **Рекомендация:** обернуть карточки в next/link (`<a>`), сохранив внутренние кнопки (избранное, стрелки галереи) как вложенные интерактивы.
- **Что проверить после исправления:** Cmd+клик/средняя кнопка открывает вкладку; Tab+Enter работает; в HTML присутствуют href на /ru/announcements/…; индексация тестовой страницы.
