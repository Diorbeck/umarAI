# BUG-006 — Локализация: «419 результаты», «11 результаты»; «Объекты недвижимость для рассмотрения»

- **Статус подтверждения:** Подтверждён (разные значения счётчика, повторные загрузки)
- **Severity:** MINOR
- **Priority:** P3
- **Среда:** Chrome (macOS), /ru/search, 27.07.2026
- **Предусловия:** нет

**Шаги воспроизведения:**
1. Открыть /ru/search — под заголовком счётчик: «419 результаты».
2. Применить фильтр Аренда → Квартира → «Применить»: «11 результаты».

**Ожидаемый результат:** правильные формы: «419 результатов», «11 результатов» (и «1 результат», «2 результата»); заголовок «Объекты недвижимости для рассмотрения» (родительный падеж).
**Фактический результат:** во всех случаях используется одна форма «результаты»; заголовок с грамматической ошибкой «Объекты недвижимость…».

- **Частота:** 100% (обе загрузки страницы, оба значения счётчика).
- **Доказательства:** скриншоты `05-search-loading-map.jpg` («419 результаты»), `22-filter-rent-apartment-11-results.jpg` («11 результаты»).
- **Влияние на бизнес:** снижает доверие русскоязычной аудитории к платформе (выглядит как машинный перевод).
- **Предполагаемая причина:** в i18n-словарях нет плюрализации (используется одна строка), ошибка в переводе ключа заголовка.
- **Рекомендация:** подключить плюрализацию (ICU MessageFormat / next-intl plural), вычитать словари RU и UZ носителем языка.
- **Что проверить после исправления:** счётчик для значений 1, 2, 5, 11, 21, 101; заголовки на трёх локалях.
