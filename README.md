# Umar-TestAI — автотесты daruz.uz

Небольшой smoke-набор Playwright: 4 безопасных read-only теста для https://daruz.uz.
Формы не отправляются, данные не изменяются, звонки/сообщения не выполняются, персональные данные в отчёты не выводятся.

## Состав

- `tests/daruz-smoke.spec.ts` — 4 теста: главная, поиск, страница объявления, локализация RU/UZ/EN
- `playwright.config.ts` — конфигурация (retry ×1, скриншот и trace только при падении)
- Отчёты: `playwright-report/` (HTML), артефакты падений: `test-results/`

## Установка (один раз)

```bash
npm install
npx playwright install chromium
```

## Запуск

```bash
npm test              # весь набор
npm run test:daruz    # только smoke daruz.uz
npm run test:headed   # с видимым браузером
```

HTML-отчёт после прогона: `npx playwright show-report`

## Примечания

- Нестабильный тест автоматически повторяется 1 раз (`retries: 1`).
- Падение теста ≠ баг продукта: сначала смотрим trace (`test-results/…/trace.zip`) и отделяем баг сайта от проблемы теста/окружения.
- Карточки объявлений сейчас не являются ссылками (BUG-007 из аудита v1), поэтому тест №3 открывает объявление кликом по `[data-slot="card"]`. Когда карточки станут `<a>`, локатор стоит заменить на `getByRole('link')`.
- В облачной среде Умара внешний доступ к daruz.uz закрыт прокси, поэтому эталонный прогон выполняется на локальной машине.
