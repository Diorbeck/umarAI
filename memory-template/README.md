# Память Умара (Obsidian vault)

Эта структура создаётся автоматически в `OBSIDIAN_VAULT_PATH`.
Позже каталог подключается к Obsidian как vault — файлы обычный Markdown с frontmatter.

- `decisions/` — решения (PROPOSED → APPROVED/REJECTED → COMPLETED/FAILED), по файлу на решение
- `tasks/` — задания агентам в структурированном формате
- `reviews/` — результаты code review с вердиктами
- `lessons/lessons.md` — уроки (одна строка на урок)
- `daily/YYYY-MM-DD.md` — ежедневные итоги (лента событий)

Персональные данные (телефоны, email) маскируются автоматически при записи.
